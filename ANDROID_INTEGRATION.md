# Android Native Integration Guide

This application is built to seamlessly integrate with a native Android application using a WebView and a JavascriptInterface. 
By bridging the web application to native Android APIs, Aura can execute system-level commands, open intents, request hardware permissions, and more.

## WebView Setup in Android Studio

1. Create a new Android Studio project with an Empty Activity.
2. In your `AndroidManifest.xml`, make sure you have internet access and other required hardware permissions:

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.READ_CONTACTS" />
<uses-permission android:name="android.permission.CALL_PHONE" />
<uses-permission android:name="android.permission.SEND_SMS" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW" />
<!-- and any other permissions needed -->
```

3. In your Main Activity, configure a `WebView` and add the JavascriptInterface:

```java
import android.annotation.SuppressLint;
import android.os.Bundle;
import android.webkit.WebSettings;
import android.webkit.WebView;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {
    private WebView webView;

    @SuppressLint("SetJavaScriptEnabled")
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        webView = findViewById(R.id.webview);
        WebSettings webSettings = webView.getSettings();
        webSettings.setJavaScriptEnabled(true);
        webSettings.setDomStorageEnabled(true); // very important for localStorage!

        // Add the interface mapping the name "Android" to our JSBridge class
        webView.addJavascriptInterface(new WebAppInterface(this), "Android");

        // Load the hosted URL of your Aura app
        webView.loadUrl("https://your-aura-hosted-url.com");
    }
}
```

## JavascriptInterface Implementation

Below is an example of what your `WebAppInterface` should look like. It must expose methods with `@JavascriptInterface` so Aura can call them natively.

```java
import android.content.Context;
import android.content.Intent;
import android.net.Uri;
import android.webkit.JavascriptInterface;
import android.widget.Toast;

public class WebAppInterface {
    Context mContext;

    WebAppInterface(Context c) {
        mContext = c;
    }

    // Checking if native permissions are granted
    @JavascriptInterface
    public boolean hasPermission(String name) {
        // Implement ContextCompat.checkSelfPermission logic here
        return true; 
    }

    // Request permissions dynamically
    @JavascriptInterface
    public boolean requestPermission(String name) {
        // Implement ActivityCompat.requestPermissions logic here
        return true; 
    }

    // Execute Native Intent action (URL or explicit packages)
    @JavascriptInterface
    public void openIntent(String url) {
        try {
            Intent intent = Intent.parseUri(url, Intent.URI_INTENT_SCHEME);
            mContext.startActivity(intent);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    // Handle deep interactions generated by the AI
    @JavascriptInterface
    public void executeAction(String type, String number, String content) {
        if (type.equals("call")) {
            Intent intent = new Intent(Intent.ACTION_CALL);
            intent.setData(Uri.parse("tel:" + number));
            mContext.startActivity(intent);
        } else if (type.equals("message")) {
            Intent intent = new Intent(Intent.ACTION_VIEW);
            intent.setData(Uri.parse("sms:" + number));
            intent.putExtra("sms_body", content);
            mContext.startActivity(intent);
        }
    }
}
```

## Bridging Summary
When running in this WebView, Aura will automatically detect the presence of `window.Android` and utilize native capabilities seamlessly, including opening deep links correctly and requesting specific native hardware features.
